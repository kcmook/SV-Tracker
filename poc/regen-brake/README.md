# 회생 제동 협조 제어 이질감 개선 PoC (HTML)

샘플 데이터 5종으로 **데이터 → AI 학습 → 최적 배분 → 1 ms 협조 제어 → 검증** 흐름을 브라우저 한 페이지에서 시연합니다. 한국어/English 전환을 지원합니다.

`index.html`을 브라우저로 열면 됩니다. 단일 파일이고 데이터와 모델이 내장되어 있습니다. Chart.js와 웹폰트는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 화면 구성
| 탭 | 내용 |
|---|---|
| 개요 | 과제 배경과 목표, KPI(기존 CAL 대비 AI 추천 개선율), 구현 흐름, 파라미터 4종 |
| 데이터 탐색 | 데이터셋 요약, 결측 처리, 노면 분류, 상관 히트맵, 분포 |
| 실측 시계열 | 100 Hz 이벤트 120개 뷰어(블렌딩 구간 음영), 파라미터가 연결된 15개는 1 ms 시뮬레이션 겹쳐 보기 |
| AI 모델 | 대리모델 성능(test R²), 실제 vs 예측, 변수 중요도, 부분의존, 운전자 습관 군집 |
| 협조 제어 시뮬레이터 | 상황 입력 → 9,720개 조합 최적화 → 기존 CAL vs AI 1 ms 시뮬레이션 비교 |
| 검증 · 기대효과 | 기존 / 최적 고정 CAL / AI 비교, 노면별 개선, 에너지 효과, AI 캘리브레이션 맵, 시뮬레이터 타당성 |

## 결과 요약 (test 574건, 고정 CAL 주행 이벤트, 대리모델 예측)
| 지표 | 기존 CAL → AI 추천 |
|---|---|
| 블렌딩 구간 저크 | −39.9% |
| 감속 추종 오차 | −18.7% |
| 에너지 회수율 | +30.9% (0.492 → 0.644) |
| 승차감 점수 | +10.2% |

대리모델 test R²는 저크 0.70, 감속 오차 0.90, 회수율 0.84, 승차감 0.70입니다. 1 ms 시뮬레이터가 실측 감속도를 재현한 오차(RMSE)는 연결 이벤트 15개 평균 0.185 m/s²입니다.

## 방법
- **전처리**: 결측값은 강우 여부별 train 중앙값으로 채웁니다. 노면은 저마찰(μ<0.4), 젖은 노면(강우 감지), 건조로 나눕니다. 교란 변수(라디오 볼륨, 시간대, 와이퍼, 탑승 인원)는 제외합니다.
- **운전자 습관**: 운전자별 페달 밟는 시간, 목표 감속도, 변조 비율로 k-means(k=4)를 돌려 부드러운형, 보통형, 급제동형, 페달 변조형으로 나눕니다.
- **대리모델**: 조건 16개와 파라미터 4개를 입력으로 하는 2차·교호항 Ridge 회귀입니다(특성 230개, λ는 5-fold 교차검증으로 선택). JS 구현은 Python 예측과 1e-9 수준까지 일치합니다.
- **최적화**: 격자 9,720개 조합을 탐색해 비용 `J = 0.40·저크 + 0.25·오차 − 0.15·회수율 − 0.20·승차감`(표준화 기준)을 최소화합니다. 제약 조건은 두 가지입니다.
  - 감속 오차가 기준 CAL보다 나빠지면 안 됩니다.
  - 저마찰 노면에서는 회생 비율을 0.6 이하로 제한합니다.
- **1 ms 시뮬레이터**: 회생 제동을 먼저 배분합니다. 회생 비율 상한, 모터 토크·전력 한계, 블렌드아웃, 변화율 제한을 적용합니다. 부족한 제동력은 유압이 채우는데, 유압 선행 시간만큼 앞을 예측하고 무효시간 30 ms와 1차 지연 70 ms를 반영합니다. 차량 상수(회생 26.8 N/N·m, 유압 82.7 N/bar)는 실측 시계열 회귀로 추정했습니다.

## 재생성
```bash
cd poc/regen-brake
python3 build/prepare.py      # 전처리·학습·최적화 → build/model.json, build/ts.json (pandas, numpy)
node build/check.js           # JS↔Python 일치, 시뮬레이터 검증 → build/sim_valid.json
python3 build/build_html.py   # → index.html
# 선택: 브라우저 검증 (Playwright, 6개 탭 × 2개 언어, 콘솔 에러·번역 키·모바일 폭)
CHART_JS=/path/to/chart.umd.js node build/verify.cjs
```

## 파일
- `data/`: 샘플 CSV 5종
- `src/`: `core.js`(모델 평가기·최적화기·시뮬레이터), `app.js`(화면), `i18n.js`(한/영 문구), `style.css`, `template.html`
- `build/`: 생성 스크립트와 산출 JSON

## 한계
- lite 샘플 데이터로 만든 PoC 수치입니다. 개선율은 대리모델 예측값입니다.
- 시계열 검증 표본은 15개 이벤트입니다.
- 승차감 라벨은 2,172건에만 있습니다.
- 1 ms는 시뮬레이션 상의 제어 주기입니다. ECU 연산 시간과 CAN 지연은 반영하지 않았습니다.
